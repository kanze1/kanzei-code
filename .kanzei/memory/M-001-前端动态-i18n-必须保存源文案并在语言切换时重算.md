静态 applyLanguage API 只能为已有 DOM 节点保存 I18N_ZH，无法记录新写入的英文 textContent。当在 HTML/JS/Dynamic 场景下将文字改为英文后切回中文，若无源文案支撑则无法恢复。当前有效方案：I18N_DYNAMIC_EN + status/live source map + 语言切换重算修复运行态；scripts/ui-runtime-smoke.mjs 覆盖 kz:error 可逆路径。
