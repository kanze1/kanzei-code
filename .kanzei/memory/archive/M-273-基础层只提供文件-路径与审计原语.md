kanzei-base 是 atomic_file、content_hash、path_form、write_log 的共用基础层。业务生命周期、项目归属、权限裁决和 memory admission 由上层决定。原子替换保护单次文件写入，不代表多文件或 SQLite 与 Markdown 的事务已经原子化。修改这些原语要核对调用者的锁、CAS 和读后核验；不能在这里加入桌面对话或记忆业务分支。
