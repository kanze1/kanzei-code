CLI --new 追加 conversation.reset，用 conversation_floor 恢复当前段，不删除共享历史。关闭过程把身份移到 retired_processes，历史仍可见。process_purge 必须区分仍有活跃 process 与只有退役历史：前者先 close_process；若工作树仍保留，则对话记录也保留并返回说明，不进入 purge_session_data。后者删除历史不碰已留下的工作树，可清 session 数据与偏好，同时保留 retired 身份防复活。改删除须检查 runtime、SessionStore、身份与偏好，不能只删侧栏数组。
