kanzei-llm 将 Protocol、Endpoint、Auth、Framing 分开，并把服务商响应归一成 LlmEvent；Part、Message、LlmRequest、Usage 是公共请求与轨迹结构。业务工具权限、项目资料、记忆晋升和 UI 文案不在协议层决定。改公共消息或流事件须核查所有 protocol 实现及 core 的消费点，不可只修一个服务商或前端。

核验方式：按 refs 读取当前实现和消费者；图用于定位，不替代源码核验。
