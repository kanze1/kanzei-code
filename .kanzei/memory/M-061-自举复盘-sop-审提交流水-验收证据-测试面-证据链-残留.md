1. **拉提交流水对时间轴**:运行区间的提交按时间聚簇+message 三段式(B1/B2/关闭)判归属;长空窗必须有解释(实验/诊断/阻塞),证据落盘与测试执行的时间差超过一轮就要警惕(R-199 差 2h16m,产出占位符 ID)。
2. **逐条复核关闭证据,不信分类断言**:凡「剩余 N 处均为 X」式断言,N 处逐一打开代码核实(R-199 的"3 处均非否决"里藏着完整否决);凡"复用既有/已有能力"表述,回读代码确认(R-199 声称复用 i18n key,实际新造)。
3. **核测试面与改动面匹配**:cargo test --workspace 全绿 ≠ 全量——项目门禁口径是 verify.ps1 十步,前端改动必须有 ui_* smoke 背书,node --check 只是语法。
4. **查证据链完整**:测试 ID 无占位符(T-…xxx 即断链)、测试记录与引用它的证据同批入库、归档条目的引用不悬空。
5. **查残留**:tracker 悬空条目([doing] 零增量取活)、工作区未跟踪实验产物、记忆跨主题覆写、双状态标记([open] [done])。
6. **产出闭环**:遗留登记 defect/req(kz defect add / kz req add),系统性缺口进 backlog,复盘结论落记忆或 tracker,不留口头结论。
