AreaRegistry 的 parent 是目录/模块包含关系，crate_deps 是清单依赖。区域扫描不是 JS import、Rust symbol 或运行时 IPC 的完整调用图；目录/脚本节点存在不代表 import 已解析。dependency_keys 收集 dependencies 类表，精确判断生产/dev/build 依赖须回读 Cargo.toml；crate 图还做传递约简，未显示边不等于无依赖。context 的 neighborhood 只取祖先、目标子树及一跳上下游，不遍历全图；弱 about 关联是推断，不是确认契约。

核验方式：按 refs 读取当前实现和消费者；图用于定位，不替代源码核验。
