## 根因候选 - D-480(fixed)

### 错误信号
- req ×1 (unknown id R-216; existing: R-286,R-283,R-284,R-285,R-287,R-235,R-101,R-242,R-243,R-245,R-248,R-249,R-264,R-281,R-288)

### 判断
- 该根因是否为可复用知识？是。工具`req`在引用不在现有有效集合的ID时会失败，这是环境/工具契约约束。

### 结论
- 可记录为fact：resource ID引用必须在已知有效集合内（如R-286,R-283等），否则抛出unknown id异常。
