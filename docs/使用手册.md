# Kanzei 使用手册

本文描述当前精简共享底座与桌面端的实际操作。架构、状态所有权与权限边界见 [系统合同](design/system_contracts.md)。

## 开始一个任务

1. 从侧栏选择或打开项目，也可以直接进入无项目通用对话；工作台支持在「项目视图」与「My Quests 任务看板（运行中 / 待确认 / 已完工就绪 / 异常四态分组）」间一键切换，可跨项目就地审批或新建隔离并行任务。右键项目支持「新建工作树并行对话」「项目模型覆盖」与项目排序，底部可折叠回看「已关闭对话」。
2. 选择模型（支持按服务商分组检索的下拉框）、思考强度（7 档）和执行档位，输入目标，使用 `Enter` 发送（`Shift+Enter` 换行，`↑/↓` 翻阅当前会话输入历史）；图片和 PDF 可粘贴或拖入，点击待发送缩略图可放大预览。
3. 输入框内支持 `@` 引用项目文件、`/` 触发斜杠命令（`/btw`、`/grill-me`、`/simplify`、`/context`、`/trace`、`/wiki`、`/plan`、`/exec`、`/pair`、`/compact`、`/clear`、`/goal`、`/model`、`/files`、`/settings`）、`$` 插入已启用技能、`!命令` 本地终端直通执行并一键喂给模型，以及 `Shift+Tab` 快速切换执行档位；处于只读规划模式时，可直接点击「批准方案并实施」切回协作模式推进。
4. 对话区查看实时步骤进度、回复正文、工具专用摘要（如 `edit`/`write` 的内联彩色 Diff、连续只读探索工具自动折叠、截图证据查看）与文件改动条；每轮结束后自动汇总展示结构化「交付验收单（Action Report）」，支持一键查看改动 Diff、运行代码门禁、复制或导出 Markdown 交付报告。支持单条消息「编辑重发」「重新生成」「检查点回退（仅对话 / 仅代码 / 两者同时回退）」「分叉」，以及顶部「`/btw` 旁路只读提问」「执行轨迹 Trace」「压缩（可指定聚焦重点）」「历史段管理」和「导出」。状态栏实时展示上下文窗口占用占比，点击可查看各模块彩色分段占比拆解。
5. 权限请求支持「本次允许」「始终允许」「拒绝」，提问浮层支持回答或「取消」；顶栏与工作台提供全局「待办收件箱（Inbox）」，可跨项目直接审批后台权限请求并查看后台完工会话提醒。
6. 自主模式支持在设置页配置「自主推进 Token 预算熔断上限」与零 Token 确定性「生命周期 Hooks」（`pre_tool` / `post_tool` / `on_stop`）。完成后核对改动文件（Diff 视图支持逐块「回退此块」）与本地验证证据。

无项目对话保留独立历史与工作目录，可使用通用工具、Skills 和全局记忆；项目级 Git 与项目记忆不混入。

## 执行模式与停止

- **结伴模式（`dev-pair`）**：围绕当前请求工作，由你控制每一步推进节奏。
- **自主模式（`dev-auto`）**：按当前请求或显式 Goal 持续推进，受权限策略、失败熔断与停止控制约束。
- **只读模式（`readonly`）**：仅开放经审计的只读观察与检索能力，硬拒绝写入与命令执行。
- **隔离模式（`isolated`）**：仅通过独立沙箱执行，不挂载宿主写权限与联网能力。

执行菜单提供 Goal 与权限策略设置；「自动放行」仍受明确拒绝规则、`.kanzei/memory/*` 硬保护及实际资源权限约束。停止通过运行控制协作取消当前轮次，以真实后台释放和 `kz:idle` 为准。

多个并行写任务可通过独立 Git worktree 隔离，由主对话检视差异后整合；Git 合并成功不等于行为验证通过。

## 对话伴生文件上下文抽屉

为了在对话中随时追溯代码上下文而无需频繁切页或切去外部 IDE，对话视图右侧内置伴生抽屉，支持「文件上下文」「活动（子代理轨迹与后台终端实时输出）」「工作树（Git worktree 并行创建、门禁验证、差异预检、合并、合并后全量门禁与丢弃）」三标签切换：

- **变更与全部文件视图**：默认聚合本轮工具触及文件与 Git 改动文件，也可一键切换至「全部文件」并按路径过滤；图片文件直接内置预览并支持点击放大。
- **就地行号定位与代码引用批注**：点击对话正文或工具摘要中的 `path:line` 引用直接定位高亮源码行；在源码区点击行号或 `Shift+点击` 选中行区间，可一键「引用到对话」或附带批注回填至输入框。
- **三态切换、并排 Diff 与逐块回退**：支持在「原文」「Git Diff（支持统一 Unified 与并排 Split 双模式，统一模式支持单 Hunk 精准「回退此块」）」「轻量编辑（带磁盘指纹防覆盖校验的直接保存）」三种模式间切换，并可下拉选择已安装的外部编辑器打开。
- **改动条联动**：点击输入框上方的改动文件条目，直接以 Diff 模式在右侧抽屉打开对应文件。
- **布局自适应**：桌面宽屏支持拖拽分隔线调整抽屉宽度；窄屏下自动切换为抽屉覆盖层。

## 记忆、技能、文件与浏览器

- **Repo Wiki 仓库百科**：侧栏「仓库百科」（或 `/wiki`）自动扫描项目的两级代码区域、内部依赖关系与拓扑层带，支持 AI 生成与手工修订持久化架构文档（`.kanzei/wiki/`），实时检测源码指纹漂移并一键增量同步，还可将模块架构摘要一键引用到对话输入框。
- **外部记忆**：侧栏「记忆」入口管理项目与全局 Markdown 记忆、已归档记忆恢复、待整理收件箱、管理对话、记忆图谱、有用性反馈与诊断（含检索历史与上下文账单）。`.kanzei/memory/*` 受硬保护，防止普通写入工具绕过记忆存储直接破坏。
- **Skills 与自定义 Agent**：侧栏「Skills」管理全局 Skills 目录、启用状态与目录导入；设置页「Agent 目录」完整展示全局和已批准项目 Markdown Agent 的状态、参数、错误诊断与源码跳转，同时支持配置模型、供应商、权限规则、提交/推送节奏、完成与等待确认提示音、快捷键速查、工作资料导出以及检查更新回执。
- **文件上下文与外部打开**：源码查看、Git Diff 对照与轻量修改统一在对话右侧「文件上下文」抽屉内完成（保存时核对磁盘指纹防覆盖）；需要重度多文件编辑时，可点击「外部打开」直接唤起本机配置的 IDE 或文件管理器。
- **外部浏览器工具**：`browser` 工具通过外部 Playwright CDP 驱动真实浏览器页面，配合前端开发调试、表格与脚本渲染验证，按资源权限执行。
- **联网工具**：`webfetch` 与 `websearch` 统一通过 `public_http` 受控公网传输（HTTPS JSON DNS 解析与公网 IP 校验），禁止访问回环、内网与云元数据地址。
- **单进程退出语义**：桌面端采用单进程内嵌运行，关闭主窗口时若有正在运行的任务或未保存编辑会先弹窗确认，确认后优雅停止会话与后台终端并退出进程。

## 常用入口

| 操作 | 快捷键或入口 |
| --- | --- |
| 发送 | `Enter`（`Shift+Enter` 换行） |
| 输入历史翻阅 | `↑` / `↓`（在输入框首/末行） |
| 快速切换执行档位 | `Shift+Tab` |
| 上下文快捷补全 | `@` 文件引用 / `/` 斜杠命令 / `$` 技能 / `!` 本地终端直通 |
| 命令面板 | `Ctrl/Cmd+P` |
| 聚焦输入 | `Ctrl/Cmd+K` |
| 新对话 | `Ctrl/Cmd+Shift+N` |
| 清空当前对话段 | `Ctrl/Cmd+Shift+C` |
| 当前对话搜索 | `Ctrl/Cmd+F` |
| 返回上一视图 | `Alt+←` |
| 文件上下文抽屉 | 顶栏「文件上下文」按钮 / 点击 `path:line` 或分支改动条 |
| 检查更新 | 设置中的「版本与更新」入口 |

遇到问题先检查活动区、日志、当前对话身份与版本徽章。更新下载成功和本地程序替换是两个步骤，安装后以实际运行的版本确认结果。
