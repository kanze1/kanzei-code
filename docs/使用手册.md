# Kanzei 使用手册

本文只描述已有操作。下一版管理设计见 [管理工作区方案](design/management_workspace.md)，实现与权限边界见 [系统合同](design/system_contracts.md)。

## 开始一个任务

1. 从侧栏选择或新建项目，也可以进入无项目对话。
2. 选择模型、思考强度和执行模式，输入目标，使用 `Ctrl+Enter` 发送；图片和 PDF 可粘贴或拖入。
3. 对话区查看正文和工具摘要，活动区查看子代理及终端。权限请求按实际资源审阅；保存的规则可在设置中管理。
4. 完成后检查产物和验证证据。停止回复、工具完成、提交和安装更新分别代表不同状态。

无项目对话保留独立历史与文件目录，可使用通用工具、技能和记忆；项目需求、批次与提交门禁不参与。使用“关联项目”接续为项目讨论，原对话与文件保留。

## 执行与停止

结伴模式 `dev-pair` 按当前请求工作；自主模式 `dev-auto` 按有效目标和项目队列推进。前后端的 profile 与主 Agent 使用相同名称，两种模式分别使用独立提示词。显式 Goal 可使对话围绕目标继续。研究任务按研究档的能力与权限运行；不会因为切换浏览页面而改变既有运行归属。

发送前确认当前对话、项目、模型和模式。执行菜单提供 Goal、协作及权限策略；“自动放行”仍受明确拒绝、托管写入和实际资源权限约束。停止通过运行控制取消当前工作，不以界面卡片消失判断后台已结束。

## 项目管理与证据

当前管理页提供需求、缺陷、交付与项目地图。普通讨论不自动成为需求。当前状态和验收以 `.kanzei/project/requirements.md`、`defects.md` 及其归档为准；测试登记在 `tests.md` 与 `tests-archive.md`。

长程工作可使用 Work Unit：`create-unit → claim → checkpoint → verify → evidence → complete`。完成需要逐条验收证据，父目标仍需整体验收；子任务结束不自动证明父目标成立。当前命令与参数以 `kz --help` 和对应子命令帮助为准。

多个写任务通过独立 worktree 隔离；由主代理检查差异后整合。Git 文本合并成功不等于行为验证通过。切换页面或查看项目知识不会转移正在执行任务的收件人。

## 记忆、技能与文件

- 全局记忆入口查看项目记忆、召回和上下文观测。命中与读取不能直接证明任务收益；候选、反馈和已确认记忆分别管理。
- Skills 由全局目录管理，启用与读取按实际工具合同执行。
- 文件编辑保存使用磁盘指纹检查；出现外部修改时先比较，再选择保留的版本。浏览器页面、原生窗口与文件分别受资源权限约束。

## QQ 机器人

左下角“社交助手”打开最近一次社交会话，首次使用打开“大肥鱼”的独立沙箱会话。顶部会话菜单切换大肥鱼、QQ 好友、群聊和 B站浏览；QQ、B站连接状态与“管理”按钮打开同一会话右侧的管理面板。窄窗口中管理面板占满会话区，关闭后回到原对话与未发送草稿。正文、输入框和工具流复用原有无项目对话。后台 QQ 执行时入口显示活动标记，会话菜单显示当前阶段；切入后可查看消息、运行中工具与后续完成结果。

先启动本机 NapCat（Windows 包可运行 `launcher.bat`），在“管理 → QQ → 连接”选择 NapCat 程序目录。应用从本机配置读取管理凭据，展示手机 QQ 登录二维码；登录后点击“配置并启用 QQ”，自动生成令牌并写入 NapCat 和 Kanzei Code，保留 NapCat 其他连接。也可手动填写管理地址、密码和两步验证码；已有 OneBot 配置在“手动 OneBot 配置”中直接填写。NapCat 程序需独立保持运行。

实际好友可通过私聊唤起大肥鱼，陌生人和临时会话不会创建助手任务。命令、文件读写和计算使用沙箱工具，工作目录 `/workspace` 中的文件持久保留；大肥鱼、QQ 好友和 B站共享个人工作区，各群拥有独立工作区。沙箱只挂载该工作区与只读 Linux 运行环境，不挂载宿主磁盘、凭据、浏览器或 Windows 互操作；沙箱内命令不联网，搜索和网页读取通过受控公网工具执行，不能访问 localhost、内网或云元数据地址。Windows 需要默认 WSL2 发行版中的 Python 3 和 bubblewrap 0.9+；隔离不可用时报告失败，不改用宿主执行。每条命令最多 120 秒，单文件写入上限 64 MiB；`/stop` 停止当前好友任务。原有普通无项目助手保留原工具，不受社交工作区设置影响。

群聊需要逐群启用。普通群消息不要求 @；系统按发言间隔批量判断是否参与，模型选择不参与时不发送内容。每轮最多一条群回复。安静时段限制普通水群判断；明确 @ 当前机器人时立即排队回复，不受水群间隔和安静时段限制。@ 全体成员、@ 其他账号和纯文字中的 @ 不触发点名回复。开始和结束小时相同表示关闭安静时段。主动搭话间隔为 0 时关闭，启用后在同一群会话中继续。群聊提供本群记忆、群回复、本群沙箱、公网查询和共享 B站读取、评论草稿能力，没有宿主终端、宿主文件、桌面控制、子代理或工具发现能力。

“群聊规则”支持逐条添加、编辑和删除，也可从 QQ 群列表选取。未保存规则可直接取消；删除只停用该群的消息入口和发送，不删除历史或记忆，重启后仍保持删除。共享人设与本群人设分别设置。本机无项目助手、QQ 好友私聊和 B站共用个人记忆；仅群聊按机器人账号和群号隔离，不向群注入个人记忆或全局偏好。旧好友记忆导入共享库并保留原文件及来源；管理页可以查看、新建和按版本修改当前范围的记忆。模型提交的线索仍按现有候选与来源流程整理。

QQ 只接收助手正文、群聊显式回复和需要处理的问题，不转发工具执行日志。权限请求显示具体操作和 `/allow 编号`、`/deny 编号`；需要回答的问题显示题目、选项和 `/answer 编号 内容`，不展示内部事件 JSON。

消息按 QQ 消息编号去重，好友消息与运行任务同时入库。记录页区分 `sent`、`failed` 和 `unknown`：明确送达、明确失败与无法确认的发送。断线和退出后的未知发送不会自动重发；重启恢复原会话、记忆和记录。

## B站

“社交助手 → 管理 → B站 → 登录”使用哔哩哔哩客户端扫码并在手机确认，扫码后即使切换标签或关闭管理面板，当前登录仍会继续同步，成功后显示账号；后端保留平台返回的完整登录 Cookie，并通过账号接口验证后保存；验证失败会结束本次挑战并保留原登录，错误会区分请求、响应解析和登录失效。凭据仅保存在本机后端，也支持高级手动 Cookie 登录。退出登录会关闭自动浏览。

个人大肥鱼、普通无项目助手、QQ 好友、群聊和 B站浏览会话共用同一套 B站工具与已登录账号：热门或关键词搜索、视频信息和可用字幕、评论及楼中楼、评论草稿。群聊调用时仍只使用本群记忆，不导入个人记忆；聊天中没有直接发布工具。

“视频”支持热门视频、关键词搜索、BV 编号或链接，使用官方播放器观看，读取视频信息、字幕和分页评论及楼中楼。助手读取的材料会明确标注：没有字幕时只读取信息和评论，不声称看过画面或听过音频。

“浏览一轮”打开原生对话，展示助手实际工具流和日志。B站浏览会话拥有 B站读取、评论草稿、个人记忆、社交沙箱和公网检索工具，没有宿主控制能力。“设置”可开启定时浏览、设置关键词、模型、间隔与安静时段。自动浏览默认关闭，登录失效、风控或连接中断会暂停，查看错误并保存设置后恢复。

助手生成的评论进入“评论草稿”；你可编辑后点击“发布评论”。发布绑定登录账号、视频、讨论串和正文版本，必须得到评论编号才显示已发送。切换账号不能发布原账号草稿；未知结果与程序退出期间的发送不会自动重试。可设置每日发送上限与间隔，浏览记录、草稿和回执本机持久保存。B站与个人助手、QQ 好友共享个人记忆，平台会话及登录记录保持各自归属。

## 常用入口

| 操作 | 快捷键或入口 |
| --- | --- |
| 发送 | `Ctrl+Enter` |
| 命令面板 | `Ctrl/Cmd+P` |
| 聚焦输入 | `Ctrl/Cmd+K` |
| 新对话 | `Ctrl/Cmd+Shift+N` |
| 停止 | `Ctrl/Cmd+Shift+C` |
| 当前对话搜索 | `Ctrl/Cmd+F` |
| 导出对话 | 对话右键菜单 |
| 检查更新 | 设置中的更新入口 |

遇到问题先检查活动区、日志、当前对话身份与版本徽章。更新下载成功和本地程序替换是两个步骤，安装后以运行中的版本确认结果。
