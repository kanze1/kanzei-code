# 对话导航与生命周期

本次聚焦无项目对话、项目开发和基础交互；研究流程重设计另行处理。

## 交互方向

- 视觉：安静、紧凑的文字列表，单一选中背景，减少每行重复的类型标签。
- 内容：固定的新建和搜索入口；项目与无项目对话共存；工具入口保留在原有位置。
- 交互：项目展开、右键菜单与焦点反馈采用轻量过渡；运行状态原地更新，不重建列表、不抢滚动。

## 数据边界

`sessions.id` 是对话记录身份，`process_id` 是执行登记和兼容 IPC 的定位键。两者不得因删除、关闭而复用。

- 名称与消息属于对话。`sessions.title` 是唯一命名来源。
- 活动进程提供运行状态、模型和工作树上下文；关闭后这些能力消失，历史对话仍存在。
- 已关闭对话仍可查看、重命名、删除。只读指不能继续执行，不代表不能管理记录。
- 置顶和排序仍使用已有偏好键，不复制出第二套偏好，也不新建冗余会话表。
- UI 将活动和已关闭记录投影为同一种行，使用同一渲染器与管理入口。`session_id` 用于去重；运行态仍由既有实时会话状态决定。
- 删除历史只清理该会话已有的记录与派生产物；不重新激活进程，不删除项目文件或遗留工作树。保留退役身份以阻止编号复用。
- 主对话是现有项目执行锚点，仍提供“清空对话”。本次不迁移数据库或破坏已有会话身份。

## 验收

1. 侧栏只显示活动对话，不显示已关闭/归档对话和三个点按钮。右键或 Shift+F10 打开 4–6 项常用菜单，低频操作进入二级菜单；已关闭对话在搜索/历史中管理。删除失败保留记录并显示原因。
2. 历史删除与重命名在关闭、刷新、重启后有效；其它项目和对话不受影响。
3. 无项目对话列表独立于当前项目；切换能恢复正确消息、草稿和运行状态。
4. 按名称跨项目搜索，包含无项目对话、已关闭对话及当前项目更早对话段；输入和轮询不抢焦点。
5. 普通开发、项目切换与已有工作台回归通过；浏览器模拟 IPC 与原生 Rust 验证分别记录。

## 2026-10-03 热修正

项目下的主对话与其它对话一样，未手动命名时显示首条实际用户输入。删除为幂等操作；对已删除会话的查询返回空结果，不创建新会话行。
