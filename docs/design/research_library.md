# 独立研究课题库

研究课题与开发项目分别建模。课题拥有稳定 ID、标题、材料类别、存储根目录和可选的关联项目列表。研究导航及选择状态全局保存，不再挂在当前开发项目下。

- 新课题写入 `~/.kanzei/research-workspaces/<id>/.kanzei/research/<slug>/`，会话数据库在该独立工作目录内。创建课题不创建或选中开发项目。
- `~/.kanzei/research-library.json` 是课题登记表，通过文件锁和原子写更新。旧项目中的课题原地登记，保留文件、运行记录及会话。不同项目中的同名目录得到不同 ID；项目从侧栏移除不移除已登记课题。
- 运行层继续接受“存储根目录 + topic slug”，由课题登记表解析。前端 `currentProject` 暂作为共享运行 API 的执行根兼容字段，开发选择另存；它不再代表研究课题的归属。
- 研究侧栏显示课题选择、新建课题及课题页面。无课题时进入创建页，不自动创建游离研究会话。关联开发项目在课题详情里管理，不改变课题存储或归属。
- 切换课题清除旧页面投影和活动会话；迟到请求不得覆盖新课题。切回开发恢复此前项目及任务。重启恢复独立的研究选择。
- 不迁移 SQLite 表。旧会话仍以原存储根及 slug 定位，新课题的会话使用独立根。目录丢失时保留课题登记并显示错误，不静默切到别的课题。

验收覆盖：无开发项目的新建课题；两个项目同名课题及旧文件不变；切换/重启/迟到请求隔离；关联项目不改存储；已有 AUTO research 和论文产物预览继续可用。
