# kanzei APP 图标设计规范（R-061）

日期：2026-08-08
状态：已落地并验收

## 设计概念

图标使用一个稳定、克制的 **K 形标记**，表达 kanzei 的核心工作流：

- 左右两笔代表主 agent 与只读子代理协作；
- 中间负形保留“对话入口”意象，避免做成单纯代码编辑器图标；
- 几何边缘在 16px/32px 下仍能识别，适合任务栏和托盘；
- 深色底与金色强调对应应用当前中性深灰 + 运行态金色的 UI 设计语言。

## 色彩

| 用途 | 颜色 | 说明 |
|---|---|---|
| 主背景 | `#0d110d` ~ `#1b1e13` | 深色、低饱和，适配深色桌面 |
| 主标记 | `#c9962e` | 金色，表达运行、推进和可见反馈 |
| 辅助高光 | `#ead18a` | 仅用于大尺寸/高 DPI 的边缘高光 |
| 禁用/阴影 | `#151a12` | 保持小尺寸轮廓清晰，不使用纯黑 |

颜色比例约为：背景 70%、主标记 25%、高光 5%。禁止在小尺寸版本加入细文字、渐变噪点或复杂阴影。

## 形状与安全区

- 画布为正方形，主标记占画布 64%～72%；
- 四边安全区至少 14%；圆角平台图标不额外叠加第二层圆角矩形；
- 16px/32px：只保留 K 形主体和单层背景；
- 128px 以上：允许保留轻微金色高光，但不得影响轮廓；
- 透明度：当前桌面图标使用不透明背景，避免 Windows 任务栏出现浅色棋盘格。

## 资产清单与验收

当前仓库已包含同一设计导出的多平台资产：

- 源图：`crates/kanzei-app/app-icon.png`（1024×1024）
- Tauri 主图：`crates/kanzei-app/icons/icon.png`（512×512）
- Windows：`icon.ico` 及 `Square*Logo.png`
- macOS：`icon.icns`
- Android：`icons/android/mipmap-*`
- iOS：`icons/ios/AppIcon-*`

验收标准：

1. 源图和 `icons/icon.png` 保持同一视觉稿，不能出现背景色/主标记偏移；
2. Windows、macOS、Android、iOS 资产均存在且尺寸由平台命名约束覆盖；
3. 32px/64px 版本仍可辨识 K 形主体；
4. 图标不包含未授权字体、外部品牌标志或用户数据；
5. 设计与 UI 的深灰/金色运行态一致。

## 后续约束

若重新绘制，只替换源图并重新生成平台资产，不在不同平台手工改色。R-030/R-050 的多进程/线程状态不改变图标主体；运行态可在窗口内部通过状态栏表达，避免同一图标承载过多状态。
