## 已验证的产品路径

1. 用户在项目页输入线路名，`process_create` 原子创建 worktree、分支和线；失败不留孤儿树。
2. 线内 agent 只写自己的代码树，共享项目资产始终写主根；不同线不再因项目级整轮租约互相等待。
3. “多线”视图每 2.5 秒读取真实协作快照，展示认领、阶段/工具、分支、步数/token、改动文件；同文件交集在任何 merge 前预警并可下钻。
4. 合并前再次取协作快照并调用既有 git 预检；干净合并使用 `--no-ff`，冲突时不执行 merge 且双方现场保留。
5. 前端 runtime/i18n/a11y/markdown 门禁通过；两条 mutation guard 可把假实现打红；浏览器 800/1024/1280 无横向溢出。
