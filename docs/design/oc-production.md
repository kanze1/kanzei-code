## 待机修订

调研与表演安排见 [待机设计](oc-idle-direction.md)。H3 的 v6、v7、v8 原始待机均有偏大的肩颈起伏，原稿不直接作为运行待机。使用 `stabilize_idle.py` 对完整视频做轻度纵向稳定，保留原视频的眨眼、衣料变化和发梢动作；没有重新拆开身体、手臂或袖子。

轻呼吸原片领口纵向峰峰位移约 13.27 px，处理后约 3.01 px，下肋约 5.47 px，腰胯约 0.62 px。数值来自区域光流，用来检查幅度，不等于自动证明动作自然。原片、处理参数和处理后检查帧均保留。

## 渲染与嘴型

PixiJS 播放完整视频帧，并在相近姿态间做 180 ms 过渡。呼吸、转头和点头的运动过程设有保护区间，身体先回到可衔接姿态再执行最新状态，语音与嘴型即时响应。跳转导出和实时播放都逐一经过区间边界，避免同一时间点得到不同画面。

独立生成的 `oc-reply-hold-v6` 在中途截断后与放手片段存在身体错位，已从运行包移除；原片保留为候选记录。当前抬手片段自带短暂停留，直接衔接与末帧匹配的放手首帧。

视频保留浅灰底，运行着色器移除背景并处理轮廓边缘；素材不是原生 Alpha 视频。每个视频配有逐帧嘴部位置、缩放和旋转数据，跟踪使用口部模板和局部面部运动，在嘴线形状变化时补充局部检测。

闭嘴和张嘴均由播放器控制，以免生成视频中的自发张嘴干扰配音。嘴部贴图使用内置 imagegen 从 v5 母版编辑，提示词在 `scripts/oc-h3/mouth-v6.prompt.txt`。开合使用实际 Web Audio 的音量包络；继续保留用户选定的 C 音色和打断清空。

同时最多保留四个视频解码实例；隐藏、减少动态效果和销毁时暂停解码。帧定位完成前沿用已显示画面与对应嘴部位置，避免在视频尚未定位完成时使用新帧的嘴型坐标。

## 制作与复现

- 原画使用内置 imagegen；母版与抬手原画完整提示词见 [v5 索引](oc-references/soft-v5-manifest.json)。本轮另编辑一张嘴部参考。
- 视频使用服务器上的 H3 FL2VA + Larry v4-600 EMA。全部生成使用同属 NUMA 1 的 GPU 4、5；固定版本、模型和参数见 [部署记录](oc-h3-deployment.md)。
- 动作提示词与批处理计划：`scripts/oc-h3/action-plan-v6.json`。原始请求、输入哈希、结果哈希和视频在 `output/oc-h3/<job>/`。
- `review.py` 做完整解码与抽帧；`analyze_motion.py` 输出口部跟踪及区域运动数据；`review_mouth.py` 显示含最大位移附近帧的口部检查图。
- `pack.py` 检查逐段复审记录后打包，去掉生成音轨、保留视频帧，保存运行文件和跟踪文件的 SHA256。
- 浏览器逐帧导出使用实际播放器及 C 配音包络，`oc-preview.mjs --export --v6` 将文件写到独立目录，避免覆盖早期样片。
