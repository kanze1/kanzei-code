## 背景与问题

旧概览已经承担完整管理职责，仍混入对话摘要、模块对话与多组运行控制；输入框按钮过多，记忆、交付和网页预览的入口层级不清晰。用户要求保留 Codex / Claude Code 的常用操作习惯，并收敛自主执行、全局记忆等自有功能的呈现。

## 目标与非目标

实现确认原型的导航、信息组织与真实 IPC 接线。需求沿用已发布的新契约；执行权限、状态机和认领规则继续由后端决定。此次不改需求存储格式，不清除历史研究/想法文件，不将浏览器夹具测试当成原生 WebView 实测。

## 讨论摘要与候选方案

用户确认：对话右侧只放子代理和终端；网页单独浮动；记忆由全局页面管理；对话工作条只显示当前与下一候选。依赖图比较过全部连线网络和横向树：选横向主干，再按选中模块展开全部直接调用者及依赖。共享依赖保留原身份，多条边在主干中收拢，避免把真实 DAG 宣称成纯树。

## 最终方案

- 左侧项目、对话与全局入口；顶部对话/管理，脱离输入框。
- 管理的需求、缺陷、交付、项目地图同级。列表无对话内容；批次用格子；详情占完整内容区，保留 AC、来源、开放问题、证据及编辑。
- 输入框保留模式、许可、模型、思考、发送/停止；自动续跑、子代理配置、旁路提问、交接和后台常驻放进更多菜单。
- 选择工作绑定项目和对话。发送前复核最新归属；当前轮不被改写，下一次发送或自动续跑显式携带 workItemId。自动续跑成功接收后消费本次选择。
- 子代理和终端共用活动栏；沿用不抢焦点、手动关闭后的抑制规则。
- 网页独立浮动，拖动、调尺寸、最大化/恢复及页面缩放；当前前台对话的 browser open 可自动拉起。后台、弹窗覆盖或用户关闭时不抢前台。
- 记忆管理可选择全局或已登记的任一项目。浏览记忆不改变当前执行根；范围过滤及编辑仍写回对应的项目/全局库。
- 设置收纳运行记录、开发规范、测试记录、并行线路；项目右键复用外部编辑器入口。高级筛选、排序和批量操作保留在管理列表的更多菜单。
- 研究空间、想法入口退出导航。需求实施前的先行调研属于需求契约，保留校验状态、失败原因与继续补齐的动作。

## 技术选型与取舍

沿用 vanilla ESM、既有 IPC、00-surface 弹层和 00-frame 拖动，不引入第二套组件库。文件差异统一红删绿增。管理详情复用现有结构化编辑器，按项目保存未提交 DOM 草稿；重新打开时读取最新文档快照。

项目地图当前基于 architecture_snapshot 的 Cargo 模块清单。无支持清单的项目显示缺失说明，不生成猜测地图。统计从最近最多 200 轮已完成记录、200 次记忆观测取样，再按时间和对话过滤：平均时长只计算有效 duration_ms；工具失败不含预期拒绝；召回、注入与读取分别展示。缺失为 —，不等于 0；记忆次数是项目记忆观测，不代表全局记忆总量。
