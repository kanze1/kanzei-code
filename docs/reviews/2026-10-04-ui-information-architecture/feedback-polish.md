# 四项用户反馈修复

2026-10-04。基线 `dfbff089`。发布结果以最终提交绑定的 `dist/verification.json` 和 Release 为准。

| 用户反馈 | 修复后的行为 |
| --- | --- |
| 手动标记也关闭不了 | 桌面手动完成使用可信用户入口，记录用户验收，保留原验收与证据；不再索要模型的格式化关闭证据。模型关闭仍受原证据校验约束，取消仍需原因。 |
| 主对话框按钮太丑 | 更多菜单改为两组整行操作，统一开关外观、间距与悬停；停止按钮补齐方形图标。复用原控件和事件，不另建一份输入状态。 |
| 运行日志不该默认展开 | 启动时收起；操作错误保留日志并显示短通知与查看入口。日志栏增加关闭按钮；收起后新事件不自动展开。 |
| 设置没有功能大纲和分区 | 五个功能分区、17 个设置组，固定大纲与位置高亮；保存栏常驻；窄窗口改为可横向浏览的大纲。分区跳转保留未保存修改。 |

定向验证：正式前端隔离 IPC 浏览器回归 34 项；既有工作区回归 57 项、待办维护回归 22 项；Rust 待办维护回归包含可信用户关闭、模型伪造入口拒绝、保留原验收、幂等重入、取消原因与既有关闭证据校验。修改后的日志和设置流程已接入整套 UI 运行时检查。

截图和断言位于 `output/playwright/feedback-polish/`，含明暗主题、中英文及 390/1000/1440 宽度。后端测试使用临时项目，浏览器使用隔离夹具；原生安装版的实际使用由新安装包承载。
