## 结论与问题清单

下面编号是本报告定位号，不是新建的 tracker issue。历史需求/缺陷编号沿用代码注释，并非断言其当前 tracker 状态。

| 编号 | 级别 | 确切问题 | 修复 |
|---|---|---|---|
| F01 | P0 | 非 Windows O_EXCL 锁释放后仍留文件；按 30 秒 mtime 清理又可能删掉活锁，破坏跨进程互斥 | 使用 std 句柄锁，关闭/退出释放，共享锁真实共存，不再按年龄删锁 |
| F02 | P1 | CAS 的检查和替换没有共同写锁；两个合作写者可同时通过检查并覆盖 | CAS 内部持可重入文件锁，覆盖检查与提交 |

| F04 | P1 | 日志路径字符压成下划线造成确定性重名；同毫秒重复写覆盖凭据 | 持项目发布锁分配持久化序号，序号成为文件身份 |
| F05 | P1 | 合法空文件与未存正文共用空 Vec，last_content 返回 None，调用方恢复旧快照 | 用已有空内容指纹区分，集中到 checkpoint_content；保持字段兼容 |
| F06 | P1 | 同毫秒或时钟回拨时，按 at_ms 选出的最后日志可能是旧版本 | 按发布序号选择终态；原 at_ms 仍用于窗口筛选 |
| F07 | P1 | 自动清理全局最旧日志，会清掉低活跃路径的最后恢复凭据 | 保留每条路径最新凭据，只淘汰被后续版本替代的历史 |
| F08 | P0 | 隔离复制失败仍覆盖/删除来源，可能丢掉唯一现存内容 | 复制成功才允许破坏来源；恢复改用共享原子写原语 |
| F09 | P1 | 窗口内对账后，恢复却查询全部历史，旧凭据覆盖较新窗口快照 | 对账与恢复使用同一批窗口内日志 |
| F10 | P1 | 窗口内合法新建随后被篡改会被删除；最新正文缺失时会恢复过时快照 | 新建也优先恢复合法凭据；缺正文时停止恢复并报告不完整 |
| F11 | P1 | 三类专用写者在发布日志前释放文档锁，围栏可能看见“新文档但无凭据” | conventions、architecture、test_record 持锁直到日志发布完成 |

### 验证

## crates/kanzei-base/src/write_log.rs

### 职责
保存专用写者的归因凭据、按窗口读取，并提供最新合法恢复内容。

### 判断
P1

### 确切问题
- F04、F05、F06、F07。

### 修改
- 项目 publication 文件锁串行化发布与清理；新日志为 `v2-<order>-<pid>.log`。
- 在旧六行编码后追加 `sequence:<order>`；旧记录仍可读，新记录按持久化序号排序。
- 利用已有 fingerprint 区分空文件与省略正文，新增 checkpoint_content，避免破坏所有 WriteLogEntry 构造方。
- 自动清理保护每条路径最新凭据；500 变成历史条目的目标上限，路径数超过 500 时优先保留凭据。
- 发布只扫描文件名；清理只读头两行，避免每次写入重新加载所有文档正文。

### 影响范围
- 记录者：memory/store、inbox、tools 专用写者、通用写入、app/files_edit。
- 读取者：managed/cross_tree；字段和函数签名保持兼容，新增一个只读方法。
- `entries_after` 仍按 at_ms 过滤，但输出改为发布顺序。旧六行中已经丢失的同毫秒顺序无法事后恢复。
- `prune_before` 是显式时间删除接口，无生产调用，保持原契约；自动清理采用保留 checkpoint 的新规则。

### 验证
- 两条确定会 sanitize 重名的路径、同路径同毫秒重复写，三条凭据均保留。
- 时钟回拨后最新发布内容仍被选中；空文件和省略正文分别返回 Some(empty)/None。
- 八线程并发发布 80 条，全部保留且每路径终态正确。
- 520 次热点写后冷路径 checkpoint 仍在；历史条目被压到目标数量。
- 旧格式读取、损坏单条不隐藏其它好记录、时间筛选均覆盖。

## crates/kanzei-tools/src/managed.rs

### 职责
捕获托管文件快照、区分合法写入与越界变化、隔离并恢复。

### 确切问题
- F08、F09、F10。

### 修改
- 无日志场景只恢复自身快照；前台日志场景把本次已筛选日志传给恢复函数，不再重新读取全部历史。

### 影响范围
- 前台 bash、无日志退化路径、background/lifecycle 的恢复调用；现有对外内部函数签名保留。

### 验证
- 制造隔离目录创建失败：修复前原内容仍被覆盖，修复后来源不动、恢复计数为零。
