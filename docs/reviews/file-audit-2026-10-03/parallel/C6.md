## crates/kanzei-app/src/run/assembly.rs（全文）

### 职责
装配一轮真实运行的当前输入、typed writer、baseline及执行/写入所有权。

### 判断
P1

### 确切问题
- 内部创建 input 后启动 Err 丢失收尾身份；Saved 路径只写 input failed，typed/session 仍活跃。旧出口实测六个状态/停止/回滚断言失败。
- 初始 user fact 被 SQLite 拒绝仍进入 provider；旧逻辑实测一次 HTTP 请求并提交了 Completed。

### 修改
- 私有 prepare_session 保留实际 store/input/writer，writer 后复用 C5 原子 Failed/Stopped；writer 前只收尾当前 input，不关闭历史 turn、不编造 baseline 来源。
- 在真实 lifecycle 内短持锁，再核本轮 halt token 并提交；提交后通知，startup 成功后才创建弱 flush。user ACK false 时禁止 provider。

### 影响范围
- coordinator::run_task 同签名调用；commands 传同一个 lifecycle，执行 owner/晚 callback Arc 生命周期保持。
- baseline/observer/notification/lease 任一后续 Err 走同一出口；无 schema、持久格式或新锁原语。

### 验证
- 七条新真实 SQLite/HTTP 回归通过：内部及已保存输入、user 拒绝0POST、四写点双拒绝回滚及真实 commands fallback、writer 前 baseline/附件失败、真实写租约等待+Stop、正常200及owner释放。

- user 拒绝仍执行provider并返回Completed/成功receipt。

### 影响范围
