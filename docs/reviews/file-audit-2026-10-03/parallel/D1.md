## crates/kanzei-harness/src/config.rs

### 职责

全局/项目配置加载、合并、缺省填充、模型解析、schema 参考及实际 loader/权限回归。

### 判断

共享配置写事务 C1 为 P1，本包添加共同 lower owner；显式 verify 合并 C2 的真实 loader 回归同源记录，不重复计根因。app writer 尚未适配，不能宣布 C1 整链已修复。

### 确切问题

旧 append、settings、models、delete 独立读改写同一文件；models 第二次读取与写之间仍可覆盖已成功保存的授权。无共同 owner，原子写本身也不能避免旧快照覆盖。

### 修改

增加 `pub fn update_config_document(path: &Path, edit: impl FnOnce(&mut toml_edit::DocumentMut) -> anyhow::Result<()>) -> anyhow::Result<()>`。现有 base 同路径 FileLock 包住 read（仅 NotFound 空）、UTF8/typed/DocumentMut 校验、同步 edit、结果 typed 校验、原字节比较与现有 write_atomic。错误传播，不扩授权、不改 schema、不增加依赖。

公开 loader 委托同一私有路径入口，测试可用临时 global/project 路径执行真实生产装配链，避免读取真实用户配置或改进程环境。原公开签名不变。

### 影响范围

当前新 API caller 为 append_allow_rule；旧公共 append callers 全仓库已搜，签名不变。后续 root M3 将 settings/model_config/delete 适配同一 owner，base 原语不变。同步闭包不允许跨 await。

### 验证

新增真实配置事务阻止并发 append 的回归，提交后同时保留文档修改、精确授权、注释与未知键；另覆盖编辑错误、前后 typed 校验、IO 读取失败保持原字节。四项定向回归各1 passed，完整 harness 前后各207 passed。等价负例移除共同锁保留新 API/测试，单个真实回归编译成功后断言失败（exit101），原字节/哈希恢复成功。首次锁探针误用 is_err 把 Ok(None) 当成未占锁，测试断言失败；已改为 unwrap().is_none() 并重跑完整流程，原失败日志保留，不掩盖为负例证据。
