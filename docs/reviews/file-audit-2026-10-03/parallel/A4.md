## crates/kanzei-app/ui/01-core.js

### 职责
提供 IPC/事件路由、同窗口偏好通道、每会话 pane/流式上下文及清理原语。

### 判断
P1

### 确切问题
- prefs get/set 没有共同顺序：晚 get 覆盖已成功 save 的 cache，晚的先前 save 可覆盖最后选择；cache 对 layout 做整层覆盖，和 Rust 两级/null 合并不一致，会丢掉 conversation_mode、split 等实际兄弟偏好。这是偏好提交/缓存来源一致性根因。
- 09 提前切 activeSessionId，15 cached shortcut 只调用 showPane，showPane 未转移三流式指针；实际 07→05 下一条 B delta 写入隐藏的 A body，切回 A 又可能创建重复块。这是 pane/stream owner 转移根因，一次计数。
- 全文其他 console、体验事件、session 路由、DOM/输入辅助、裁剪、poll 区域未发现有实际影响的问题。

### 修改
- 私有 Promise 队列按原调用顺序执行 get/save；排队前冻结保存请求，成功才更新 cache，失败队列继续。
- cache 按 native 已提交 patch 规则合并：顶层 Option/null、memory_view 合法值、layout 两级/null、UTF-8 64KiB 上限、几何值整体替换。
- showPane 按 outgoing pane.dataset.sessionId 保存到既有 sessionStreams，并恢复 incoming 指针；同 pane 不覆盖刚更新的活动指针。没有新增状态副本或不可达后台限制。

### 影响范围
- prefs 直接 caller：03-layout/workspaces/shell、08-auto/compose-runtime、18-startup、22 偏好/视觉、24-memory-graph/schedules、28-async-workspace。公开 Promise 参数/返回/失败语义不变，同窗口读写时序确定。
- showPane 直接 caller：15 的历史缓存/装载/新段；09 调用 15，07 和 05 消费所属 pointer。reset、discard、evict、withSessionRender 原清理/异常恢复合同保持。
- IPC、持久化格式、session 身份、lock/schema 兼容。

### 验证
- 15 项真实 owner + 实际 05/07/15 caller 回归通过；09 的提前设置 process/session 合同按已读源码复现，未声称执行整个 09 模块。
- 故意延迟 get/set，证明 durable/cache 最后值；失败读写后队列继续；layout/null/忽略负载；实际文本与 reasoning/head 隔离、切回不重复、同 pane 保留、嵌套异常恢复、clearChat、discard/evict 保留 active/running。
- 固定旧基线 owner 的 --before 为 10 项 ERR_ASSERTION 失败、5 项 PASS；不是编译/fixture 初始化失败。
