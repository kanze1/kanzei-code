## 工具失败的实际原因

发现并修复了一处真实死锁：普通文件锁到期重试时仍持有全局登记表互斥锁，重试成功后再次获取同一把锁，导致当前工具及其他文件操作一起等待。现在到期按时间预算返回；29 项锁与原子写测试通过。

历史记录去重后共见 24,509 次工具完成记录。可用记录最新时间为 `1790361167220`，不是本次日期的实时样本。其最近 14 天的常见非成功类别：bash 非零退出 23、defect 登记校验 9、edit 需确认 7、Git 目录参数 6、test_record 可纠正输入 5、req 登记校验 5。这里不能据此计算当前失败率，也不能把命令执行失败与工具故障混为一项。

本次先解决真正卡住执行的死锁、异常清理、网页后端失败与输入错误分类。未自动重试普通写文件、Git 或 tracker 等有副作用的调用。

主目录完整回归还发现本地预览服务偶发 Windows `ConnectionReset (10054)`。响应发送后增加显式发送端 shutdown，按照 [Microsoft 的 Winsock 关闭建议](https://learn.microsoft.com/en-us/windows/win32/winsock/graceful-shutdown-linger-options-and-socket-closure-2) 改善连接收尾；这不能证明所有连接重置都由同一原因引起。回归连续验证 64 次真实 HEAD/GET 连接，不通过重试隐藏失败，已通过。已退役记忆画布残留的空转逻辑也已删除。

## 压缩调研和决定

选择“完整历史保留 + 有限观察摘录 + 带约束的摘要 + 近期原文”，并验证替换后的估计 token 确实下降。自动压缩使用 runner 的真实预算判断；界面里的容量提示不再声称固定 70% 就是自动压缩阈值。

调研依据：

- [OpenAI Compaction](https://developers.openai.com/api/docs/guides/compaction)：Responses 支持由阈值触发的服务端压缩与不透明压缩项；独立 compact 返回的窗口应按文档使用。这是 API 能力，不等于已证明 Codex CLI 使用同样策略。本次没有把这条服务商专有路径当成通用持久格式。
- [Anthropic Compaction](https://platform.claude.com/docs/en/build-with-claude/compaction)：提供主动触发、token 阈值和客户端压缩选择。客户端方案适合 Kanzei 的多模型入口。
- [The Complexity Trap](https://arxiv.org/abs/2508.21433)：作者在代码代理配置中比较观察遮蔽和模型摘要，提醒不要仅凭“摘要更聪明”判断成本及质量。作者实验不是 Kanzei 的效果数据。
- [ACON](https://arxiv.org/abs/2510.00615)：将失败分析用于改进压缩规则，为后续回放评估提供方法。本次没有声称复现论文中的下降比例。

下一阶段质量评估使用固定任务回放：比较不压缩、只摘录、约束摘要三组，核对任务成功、约束遗漏、文件/工具指针恢复、输入 token 与压缩成本。现在已有防退化测试，尚无可报告的真实任务质量增益百分比。

## 定时任务例子

保存为项目 `.kanzei/schedules/daily-review.md`；更常见的操作可以直接在面板编辑。

```yaml
---
name: daily-review
enabled: true
when: 每天 09:00
host: app
utc_offset_minutes: 480
catch_up: once
agent: readonly
model: primary
timeout_secs: 1800
max_steps: 32
steps:
  - prompt: |
      检查最近变更，报告仍需处理的实际问题。
writeback:
  - notify
  - file: reports/daily-review.md
---
每天一次项目检查。
```

支持每分钟/小时、每日、工作日和每周频率。`system` 使用当前 Windows 用户的任务计划程序，应用关闭后也可以执行；电脑关机或用户未登录时不能保证运行，睡眠唤醒取决于系统电源策略。系统任务偏移须与本机一致。服务器任务指定 `server:ENV-001`，使用已登记且允许执行的 SSH 环境；远端需安装本版 `kz`。时间使用明确 UTC 偏移，尚无独立 IANA/DST 时区规则。

新启用不补历史任务。`once` 最多补最近一个错过的槽位，`skip` 跳过迟到任务。只读为默认档；dev 定时任务保存独立候选代码，不自动写回主目录。无人值守中需要询问的工具按既有 NonInteractive 策略拒绝并记录，后续执行继续。
