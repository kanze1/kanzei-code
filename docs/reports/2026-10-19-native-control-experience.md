# 原生控制提示、操作轨迹与急停

本批从 `a69363af` 建立隔离工作树，主目录未提交的在途修改不参与实现或发布。冻结前已检查并快进到主目录新提交的 `a1a152e2`，将已提交的 Chat Completions 工具 schema 修复纳入本次统一门禁。此前 `1964f9f9` 的原生 17 项及真实 Luna 表单验收只覆盖执行和权限边界；持续提示、动作反馈及全局急停当时缺失。

## 实现约束

- 原生控制条与位置提示使用独立、置顶且不抢焦点的桌面窗口。控制条展示真实目标、当前状态、最近三步与停止按钮；主对话展示有界完整动作轨迹。位置窗口穿透输入，按可访问性快照标出目标，点击完成派发后显示波纹。发送与观察是不同事实，不将 dispatched 标成已核验。
- 全局键盘钩子只处理活动控制期间的 Escape。回调只提交停止信号，不等待 IPC、UI 或进程收尾；模型发往目标应用的键带引擎专用输入标记，不能误触急停。非控制期间 Escape 正常交给应用。实现参照 [Microsoft LowLevelKeyboardProc](https://learn.microsoft.com/en-us/windows/win32/winmsg/lowlevelkeyboardproc)。
- 桌面控制权绑定 project、process、session、run 与窗口能力。不同对话不能交错持有控制权，旧停止请求不能转移到新任务。停止先撤销能力并取消输入进程，再等待 OS 退出、输出管道与动作区间收尾；后台确认之前保持停止中或停止未确认。普通会话停止、控制条停止、Escape 和 TCP 断开共用取消与收尾路径。
- 控制提示完成事件订阅和初次渲染后才接收动作。提示重载或键盘钩子退出触发停止；提示或急停不可用时明确拒绝执行。动作框不抢焦点，控制条避开当前点击位置；减少动态效果偏好关闭动画。
- `runtime_shutdown` 等待后台所有者退出并返回确认，由窗口持有者关闭 UI；不在 IPC 回复前退出应用，以免吞掉验收回执。
- 关闭主窗口时先取消并回收原生输入，再退出同属它的提示窗口，辅助窗口不能独立保活 UI 进程。
- 取消覆盖向输入进程写请求的阶段。控制权登记时在同一控制锁内复核窗口能力，避免等待提示就绪期间已被停止的旧调用重新开始。
- 状态发布先串行取得发布权再取最新快照，过时的 running 状态不能在停止确认后重新显示目标框或启用 Esc 捕获。按 process/run/window 匹配与取消在同一个控制锁内完成。
- 原生控制事件登记为全局事件，主界面通过统一的运行事件路由接收，辅助窗口复用基础订阅机制。停止及控制状态变化后重新读取窗口绑定，菜单不会继续显示已撤销的连接。
- 控制停止等待后台任务确认后，再由 GUI 核对本地执行器收尾；后台重启丢失登记也不能省略此步骤。命令回执确认指定的控制标识，最新全局状态另由事件与查询投影，后继任务不会让旧停止回执变成假失败。
- 首次原生批次通过执行边界 17 项及 Windows 窗口层 6 项，随后在切换会话后的首次 Escape 输入失败，原始工具回执为 `Selected window does not own keyboard focus`。点击和按键现在共用前台激活确认：`SetForegroundWindow` 后通过有时限的 `WM_NULL` 消息等待目标处理激活，再检查前台归属，不重试或用固定延时掩盖。参照 [Microsoft 跨线程前台激活说明](https://devblogs.microsoft.com/oldnewthing/20161118-00/?p=94745)。原始失败与旧版本已通过证据分别保留，不挪用为新程序的通过记录。
- 随后的焦点采样发现，UIA 从按钮切回输入框时也会短暂失去前台；激活确认同时用于 `SetFocus` 后。人工真实点击授予测试窗口前台后，“点击提交→切回输入框→发送 Escape”的独立回调检查通过。系统拒绝前台切换时明确失败，需要真实用户激活，不通过抢焦点技巧或重试绕过。

## 验收范围

最终源码冻结后集中运行完整工程门禁，再对同一发布程序依次执行原生执行与边界、原生控制体验、真实 Luna 表单三组。每组保留首轮结果，不以重复运行换取通过。

控制体验验收覆盖：真实表单提交与动作记录；桌面控制条和位置框；引擎标记 Escape 的正常输入；独立 OS Escape 在目标应用前台急停；非活动期间 Escape 放行；真实 OS 鼠标点击控制条停止、对话归属与陈旧停止拒绝；普通停止；阻塞控件回调期间取消并独立核对输入进程消失；迟到供应商响应不能恢复控制。界面门禁覆盖发送/核验区分、停止中、停止失败、缩减动画和窗口标题注入。

原生五场景通过后，关闭验收程序的页面可能先于其销毁调用的回执消失。结束判据独立等待主窗口和辅助窗口关闭、OS 进程退出，仅接受该次销毁引起的特定执行上下文关闭错误，其余调用错误仍判失败。

实际命令、源码、程序与安装器 SHA-256、完整门禁和首轮运行结果存入当前提交命名的 `output` 发行回执。本文件描述实现及判据，不能代替实测。已提交到目标应用的动作不能撤销；停止确认保证没有后续原生输入，不能宣称取消外部应用自行启动的业务。
