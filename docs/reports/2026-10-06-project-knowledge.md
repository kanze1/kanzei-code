# 项目知识与层级记忆改造验证

日期：2026-10-06。设计与源码已完成；本报告记录定向验证，完整发布证据由干净工作树的 `dist/verification.json` 绑定交付提交。

## 已交付

- 数据结构确定为 [ProjectKnowledge v1](../design/project_knowledge.md)：包含关系构成项目层级，依赖单独构成有向图；Markdown 记忆保持真源，投影可重建。
- 项目开关默认关闭，新建项目显式选择初始化。已有项目开启后直接投影当前代码与已有记忆；关闭保留记忆并停止层级上下文加载。
- 项目职责、接口、约束、环境、流程和踩坑通过现有字段表达，保留多模块关联、出处、修订指纹和候选状态。事实可引用真实源码、文档或架构决策。
- 开跑只加载概览；`architecture action=context` 加载目标模块、祖先、一跳上下游的边界知识。项目级职责和约束可随模块上下文加载，内部无关事实不全量注入。
- 架构页、记忆页和文件浏览使用同一层级组件；详情打开原始记忆。当前工作树提供结构与代码指纹，主项目提供记忆与标注资产。
- 退役平铺事实常驻索引、旧 scope×category 总览卡、架构快照 graph 兼容字段、项目记忆默认写入普通召回已停用的 global 库，以及目录用途摘要永久有效的行为。
- 文件/目录用途仍是可重建的 AI 摘要。文件变化使摘要失效；目录生成需要来源完整且有效，并在生成前后核对指纹。旧 Markdown 和历史标注没有批量清空。

## 发布验证前的旧测试修正

`ui-lint-smoke.mjs` 的静态部分通过，但其后串联的旧 `ui-narrow-layout-smoke.mjs` 仍按停靠网页预览断言。当前产品已在 [familiar_workspace.md](../design/familiar_workspace.md) 确定使用独立浮窗。

在 1280×840 下，把本次修改的 UI 文件全部替换为 HEAD 内容进行只读浏览器对照：HEAD 和工作区的预览、对话、输入区几何完全一致；浮窗宽 920px，旧断言要求 456.96px。现已将旧测试同步到当前浮窗设计：7 个预览尺寸场景与越界反例自检通过；原 35 组任务侧栏/日志检查继续保留。没有改动网页预览布局。

完整门禁另发现记忆图谱在 1280×690 下适配缩放约 0.27，旧阈值隐藏全部记忆编号。编号现始终参与防重叠排版，专项浏览器复查显示 10 个可辨编号；11 组模型、5 个变异守卫、677 节点规模和减少动效检查同时通过。

正式 `verify.ps1 -Full` 在隔离工作树执行；正在开发的其他改动不进入本次提交。联合发布包含已提交的对话删除残留、无项目收件箱导航和工作提示条前端修复。

## 能力边界

Cargo crate 依赖从真实清单提取；普通项目目前生成代码目录层级，尚未解析语言特定的 import 和运行时依赖。弱关联明确显示为推断，缺失区域进入复核；候选与失效经验不作为有效约束加载。
