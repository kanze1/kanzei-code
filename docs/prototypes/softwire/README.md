# Softwire 操作台体验版 · V4

对应 [上下文、记忆、工具与工作台设计](../../design/softwire_context_workbench.md)。

视觉方向：延续 Kanzei 暖白、灰绿与少量橙色。用空间、连线、形态与状态表达结构，文字留给目标、名称、版本、问题与证据。主执行是视觉中心，依据、子任务、工具和产物各有位置，避免所有模块等重排列。

内容安排：需求与批次运行 → 可点击的工作网络 → 模块管理与对话 → 同一处输入和执行设置。提问、决策复核和交付反馈集中到工作消息。

交互方向：运行模块缓慢呼吸，实际模拟事件才沿连线流动；悬停只追踪关系，点模块才切换收件人。对话框可停靠或拖动悬浮，标题显示项目与接收者一次。已有待办安静留在收件箱，新来信不抢焦点；减少动画时关闭呼吸与过渡。

所有文件、agent、模型档位、版本、计数和状态都是示例；没有读取项目内容或调用真实模型。操作自动产生演示回执，草稿、消息、版本状态、查看位置与悬浮位置保存在当前浏览器，刷新可继续体验。

## 打开

`node docs/prototypes/softwire/serve.mjs`，打开 `http://127.0.0.1:14078/`。可传入其他端口，例如 `node docs/prototypes/softwire/serve.mjs 14079`。仅提供本目录三份静态资源；服务器不接收输入，现场保存在浏览器 localStorage 中。

右上角“体验中”可切换为手动演示；旁边的体验选项可重新开始，并立即撤回这次重置。回归检查使用 `?manual=1`，禁用自动推进与持久化以保证可重放。

## 四层交互

项目 → 项目工作台 → 模块管理 → 具体依据。模块管理中的原文、交接、请求快照和工具结果都可继续点开；查看依据保留收件人和草稿，返回恢复原入口。查看旧版依据时，后台的新版生效不会改写已打开的片段。

## 可试路径

1. 点旧版记忆，并排比较 v3 / v4，选择“使用 v4”；版本会先进入待生效状态。
2. 默认约 1.2 秒后自动模拟新请求，采用排队的版本、工具设置和用户指令；历史请求保持原样。也可切到手动模式并点“模拟下一步”。
3. 点任意模块进入管理页；切到模块“对话”或直接发送。工具对应工具管理 agent，记忆对应记忆管理 agent，子任务直接对应它的子代理。
4. 点输入左下的层叠图标与用量数字，查看七类来源、纳入/排除状态和片段版本；归档区可展开原文或安排后续召回。
5. 输入消息，收件人、对象、发送按钮一致；发送原文完整保留。切模块/项目/工作消息时各自保留草稿，发出后先显示排队。
6. 进入“回放”，选择历史步骤；输入会提示返回当前，防止操作旧执行。
7. 打开执行设置，调整模型档位、工具范围与子代理派发；显示后续请求生效。
8. 切到另一个项目再返回，草稿、选择和队列各自保留；全局概览没有跨项目群发框。
9. 顶部直接看所属需求、当前批次、阶段和运行/等待状态。点批次“收口本批”后，进入快照验证；若验证问题未回复就继续等待。回复被处理且验证完成后，才形成示例提交与检查点。
10. 点“工作消息”或来信小窗，像回工作消息一样回复提问、决策和反馈。快捷选项先填入输入框，再发送；由自动演示产生回执。处理完成后输入区收起成“返回工作”，回到原模块和草稿。关闭来信只收起提示，不删除事项。
11. 一边输入，一边点“模拟来信”，原来的接收者和草稿保持。处理消息后点“返回刚才的工作”，回到原模块与草稿。
12. 点输入框右上角悬浮图标，或直接拖动标题栏，把对话框移到内容旁；可用方向键移动，一键停靠。默认悬浮位不挡住节点和待回复入口。窄屏恢复停靠，始终是同一个输入节点。

## 验证

2026-09-28 第四版通过 **81 项原有交互回归 + 40 项新增体验检查，共 121 项**，浏览器无 page error。新增检查覆盖四层进入/返回、固定版本依据、自动回执、后台跨项目送达、刷新恢复草稿/排队/悬浮位置、重置撤回、损坏数据回退和存储不可用时继续输入。

检查了 1440×950、1280×800、1050×735、1024×768、800×600、390×844、320×768 七种窗口：无横向溢出；五种桌面窗口输入区均留在可见范围。已查看桌面、悬浮、记忆管理、收件箱和窄屏截图。中文输入法保护通过合成 composition 事件检查 DOM/焦点/草稿保持，不代表真实系统输入法验收。

本机可重放检查位于 `output/playwright/softwire/`：`check-workbench-v4-regression.mjs` 与 `check-workbench-v4-experience.mjs`；结果为相应的 `verification-v4-*.json`。截图包括 `v4-experience-home.png`、`v4-evidence.png`、`v4-receipt.png`、`v4-evidence-mobile.png` 及七种窗口的回归截图。旧版本检查保留为历史记录。产品脚本 `softwire.js` 和 `serve.mjs` 的 `node --check` 通过。

本次改动与验收见 [V4 体验版记录](../../reports/2026-09-28-softwire-experience-v4.md)。上一轮视觉判断见 [V3 验收记录](../../reports/2026-09-28-softwire-ui-acceptance.md)。自动断言保证操作契约，不替代首次用户的理解测试。

本原型没有接入真实 agent、Git 提交、记忆写入或检查服务；上述结果只验证交互设计。引擎改造与原生桌面验收见 [总体重构设计](../../design/softwire_runtime_refactor.md)。
