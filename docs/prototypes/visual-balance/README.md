# Kanzei 视觉原型 03 · 橙青点缀 · 2026-10-20

视觉方向：完整沿用发行版的底色、正文色、明暗层次和侧栏纹理，以橙色、青色的短线、小图标、编号和开关增加点睛感，配合较轻的字重与细轮廓整理界面。

内容安排：从已发行的 `build-8fb9f71d` 读取实际 HTML、样式、模块和资源，在隔离示例中查看对话、新对话、管理、记忆、Skills 和设置；顶部评审工具可在同一份数据上切换发行版对照、深浅色与 420px。

交互方向：页签保持完整点击面积，悬停背景只包住文字附近；活动图标与数字在同一行自然排布，数量增加时按钮随内容展开；宽窄切换和悬停短促过渡，遵循减少动态效果设置。

## 配色分工

- 页面、侧栏、输入区、弹层、代码块、气泡和状态栏均保留发行版的实际底色；标题、正文与辅助文字沿用现有色阶，侧栏纹理也保留。
- 橙色沿用发行版适配值：浅色 `#c56500`，深色 `#ff8700`。用于发送、顶层当前页签短线、当前对话标记、工作选择、运行数与进行中的批次。
- 青色沿用发行版适配值：浅色 `#006579`，深色 `#39d8f6`。用于管理页的当前页签及编号、完成进度、已启用的技能开关、选中的记忆编号，以及已有资源和成功反馈。
- 正文、长标题、普通计数保持现有文字色阶。提示色以小面积重复呼应，不设置全页面积比例。
- 代码高亮、红绿差异与错误、警告的语义色保持发行版规则。
