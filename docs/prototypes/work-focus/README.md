# 工作展示栏原型 · 2026-10-20

视觉方向：沿用 Kanzei 的中性表面和橙色状态，用单行层级与按需展开减少对话页的固定占位。

内容安排：上方切换三种方案，中间运行真实前端的隔离 IPC 预览，下方解释取舍。演示覆盖空闲、当前工作、下轮切换与长标题，支持浅色、深色和 420px 工作区。

交互方向：方案切换只更新展示位置；工作详情以短促淡入展开；选择时给出明确的当前或下一轮生效反馈。遵循减少动态效果设置，不加入装饰动画。

## 三种方案

- A · 单行工作条（推荐）：独占 36px 行高，当前与候选在一行；空状态只留一句提示和操作。窄屏将下一项移至工作详情。
- B · 标题栏入口：复用现有页头，点击“工作”展开当前、下一项与选择操作。独立展示栏占位为 0。
- C · 输入区上下文：工作入口放入输入区，靠近下一次发送；本轮工作继续明确显示在弹层中。

## 运行

```powershell
node docs/prototypes/work-focus/serve.mjs --port 14128
```

打开 <http://127.0.0.1:14128/__work-focus/>。

该服务复用 `scripts/ui-preview/server.mjs`，通过同源预览框架加载真实产品的 HTML、CSS 与 JavaScript；只在预览文档中注入提案的 DOM/CSS。工作编号与内容为示例。按钮操作仅更新演示状态，不连接模型，不改项目需求或正式前端文件。

原设计切换使用原栏布局的本地重现及同一组示例状态，方便对照。原型验收与截图在 `output/playwright/work-focus-20261020/`。
