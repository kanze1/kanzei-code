# 工作台优先交互原型

对应 [R-381设计](../../design/workbench_first.md)。日期：2026-09-28。

视觉方向：延续 Kanzei 的暖白、深灰与橙色，以宽松但清楚的项目行组织工作；主视图不摆聊天框。

内容安排：首先看项目当前工作和待处理事项；进入项目后看概览、工作及多个对话；重型能力收在项目详情。

交互方向：只有切换页面时轻微渐入；条目详情抽屉短距离进入；后台更新只修改进度文字和进度格，不让整页重播动画。减少动态效果时禁用这些过渡。

所有数据均为示例。按钮只修改当前页面内存，不会调用真实模型、写tracker或影响运行中的项目；刷新页面恢复初始状态。

## 打开

运行 `node docs/prototypes/workbench/serve.mjs`，打开输出地址。静态资源仅来自本目录，服务只监听127.0.0.1。也可直接打开index.html。

## 可操作路径

- 工作台：查看每项目的需求和批次，点进度标签查看条目；点项目进入项目空间。
- 项目：切换概览、工作、对话；对话有项目内的会话列表和输入框；返回工作台。
- 项目能力：显式查看和切换示例子代理开关；不影响任何真实执行。
- 待我处理：认可决定、纠正并选择作用范围、认可一次试用；反馈回到所属项目。
- 模拟更新：只更新阅读器进度与时间；复核草稿和当前页面保持。
- 新目标：必须选择已有项目，暂存示例目标；不自动开始执行。
