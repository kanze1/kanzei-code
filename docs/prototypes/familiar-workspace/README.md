保留熟悉的侧栏、对话、输入和红绿差异。项目地图改为横向主干和局部依赖，下方显示运行统计；对话清单只显示当前工作与下一候选；子代理和终端共用活动栏，网页独立浮窗。

## 打开与试用

[打开当前原型](http://127.0.0.1:14105/)。地址不变，刷新后可用，之前的草稿、设置和验收反馈继续保留。需要手动启动时：

```powershell
node docs/prototypes/familiar-workspace/serve.mjs --port 14105
```

重点验收这四组：

1. **管理 → 项目地图**：先看横向主干，点击 `kanzei-core`，应切换为“使用方 → 当前模块 → 直接依赖”。再切回主干。检查结构和关系是否容易读。
2. **项目地图下方 → 项目运行**：筛选时间和对话，查看平均时长、工具调用、失败和记忆召回/注入/读取；点运行记录返回所属对话。执行一次演示后重新进入，或点击刷新，可看到新增记录。
3. **对话 → 工作清单**：只看正在进行和下一候选。点击“调整 / 更换”手动选取；点击条目仍打开完整信息。运行中切换应明确显示“下轮切换”，这一轮的需求编号保持不变；原工作进度保留。
4. **左下问号 → 演示工具调用**：子代理与终端在同一活动栏，网页单独弹出。拖动标题栏、拖右下角、切换 75% / 125%、最大化后恢复；关闭网页不应关闭活动栏，切换对话后各自保留状态。网页里的书签也应保留。

试用说明中的“验收与反馈”可保存意见并导出。重置示例保留反馈。Ctrl+P 搜索页面；Shift+F10 打开已聚焦项目的右键菜单。浮窗标题和尺寸手柄也支持方向键，Shift 加快调整。

## 保留的入口

- 需求、缺陷、交付、项目地图同级切换；批次保留格子，不显示数字进度。需求正文、稳定 AC 编号、来源、证据和执行记录在完整页面。
- 全局与所有项目记忆统一从左下“记忆管理”进入。
- 运行记录、开发规范和测试记录归设置；VS Code 从项目右键打开。
- 文件页、文件索引、项目工具菜单、想法、研究入口不再出现在本版原型中。

## 数据与接入范围

架构来自本机仓库的 Cargo 清单，项目右键会实际打开当前仓库的 VS Code。其他运行、子代理、终端、需求与交付使用浏览器中的示例；浮窗里是可交互的示例网页。未连接正式 agent、进程、tracker 或运行遥测服务。

运行统计由六条明确标记的示例记录，以及本地演示运行聚合。平均时长仅计算计时完整的已完成运行；工具失败、规则拒绝和手动停止分开；记忆召回、注入、读取分开，缺失观察显示“未记录”。新演示没有真实记忆事件，不虚构读取记录。

需求展示沿用已发布的 `format: 2 / revision / spec / evidence / gaps` 结构，保留旧格式与未知字段可读。示例内容随本版更新时保留既有来源和证据，并把旧版本证据标记为待复核。正式接入应复用原有存储与捕获流程。

会话高级动作、待回答/决定复核、工作条目依赖、子代理工作树采纳、记忆图谱、真实连接配置仍未完成整套原型流程，详见功能归属报告。
