## 右侧运行面板

- 子代理、终端、网页预览共用对话右侧容器，通过标签切换。
- 当前对话首次产生对应调用时展开；后续更新只刷新内容，不抢走手动选中的标签。
- 用户关闭后，同一轮后续事件不反复弹开；正文保留结果入口，可主动恢复。
- 后台其他对话只更新自身数据，切回后可查看，不切当前页面、不替换当前预览。
- 停止主运行同时停止本轮演示工具；单独停止工具只改变该工具状态。刷新后暂停，不把旧运行伪装成仍在执行。
- 验收用的「演示工具调用」放在试用说明及空白对话快捷操作里；不把它当真实 agent 执行。

正式研究退役与移除想法仍需后续应用代码接入。本轮将它们从原型和新导航方案中去掉。
