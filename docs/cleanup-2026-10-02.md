恢复某个分支时先查看 bundle 的原名，再显式导入需要的分支，例如：

```powershell
git bundle list-heads 'C:\Users\kanzei\Documents\kanzei-archives\2026-10-02-cleanup\repository.bundle'
git fetch 'C:\Users\kanzei\Documents\kanzei-archives\2026-10-02-cleanup\repository.bundle' 'refs/heads/kanzei/softwire-workbench:refs/heads/kanzei/softwire-workbench'
```

有本地改动的工作树按原 HEAD 重建，先用 `git apply working.patch` 恢复相对 HEAD 的完整工作文件差异，再用 `git apply --cached index.patch` 仅恢复暂存区，最后恢复 local-files.zip。空补丁跳过；manifest 中记录的删除与链接分别核对。压缩备份已经检查完整性和文件指纹。target、node_modules 等可重建缓存未保留。
