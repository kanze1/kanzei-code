---
name: skill-creator
description: 创建或改进可复用的 Skills。用于把稳定的工作流程、专业知识或用户提供的范例整理为技能。
---

把技能保存到全局目录中的 skills/<name>/SKILL.md，目录名与 name 一致。全局目录以运行环境提供的 KANZEI_HOME 为准，未设置时为用户主目录下的 .kanzei。

先从用户请求中确定技能的能力、触发条件和输出。只在缺失信息影响结果时澄清。用简短的 description 说明什么时候使用；正文保留会改变执行决策的步骤、约束和验证方式，避免重复通用常识。

入口使用 YAML frontmatter，必须有 name 和 description。name 使用小写字母、数字和连字符，最多 64 个字符。默认允许按任务自动选择。大量条件资料放 references/，重复且可靠的操作可放 scripts/，输出模板放 assets/；仅在确有用途时添加这些文件。

修改现有技能前读取原文和引用资源，保留用户明确要求和有效的调用规则。检查 YAML、名称、引用路径和新增脚本，用典型请求验证其是否适用。已有授权继续有效，技能不会扩大任务或授权范围。
