# 项目约定的来源

项目规则由 `.kanzei/project/conventions.md` 维护，前端可查看和编辑，按保存后的内容完整注入。它只记录该项目的技术栈、真实构建/测试入口、架构约束与用户决定，不复制 Agent 工作流程、工具参数或默认验证节奏。

缺少项目规则时，先读项目清单、README、测试/发布配置和用户要求，再通过 conventions 创建简短草案；每条可核查约束附来源，不把猜测变成既定规则。空项目只记已确定的约束，未决定事项标明待定，生成规则不应阻塞实际开发。

已有规则以用户编辑结果为准。重新生成只提出建议草案，待用户在前端采用；明确要求定点维护时才基于最新版本 patch。用户对任务的明确要求优先，不为重复确认已有授权停工。
